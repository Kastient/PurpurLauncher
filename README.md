# Purpur Launcher

Удобный лаунчер для Minecraft с поддержкой модов и сборок.

### Что есть в лаунчере:
- Все версии игры и загрузчики (Fabric, Forge, NeoForge, Quilt, Vanilla)
- Скачивание модов, ресурспаков и шейдеров прямо в лаунчере
- Быстрый перенос сборок и миров из других лаунчеров
- Счетчик наигранного времени
