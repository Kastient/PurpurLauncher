## ⚡ Особенности лаунчера

- 🎮 **Все версии и загрузчики:** Поддержка всех официальных релизов и снапшотов Minecraft (Fabric, NeoForge, Forge, Quilt, Vanilla).
- 📦 **Каталог Modrinth:** Поиск, скачивание и обновление модов, ресурспаков и шейдеров прямо в интерфейсе клиента.
- 📥 **Перенос сборок:** Бесшовный импорт профилей, миров и конфигов из TLauncher, Prism Launcher и Modrinth App в один клик.
- 💬 **Discord Rich Presence:** Красивый игровой статус в профиле Discord с кнопкой на наш Telegram-канал.
- 🔄 **Автообновление клиента:** Автоматическая тихая установка обновлений прямо в лаунчере без лишних действий.
- ⏱️ **Учет времени:** Точный подсчет общего и сессионного времени в игре.
- 🎨 **Пиксельный дизайн:** Уникальный темный интерфейс в фирменном стиле Purpur.
