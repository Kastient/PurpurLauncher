# Фикс багов

- Исправлены скины и плащи offline-игроков в Purpur Launcher.
- Лицензионные Microsoft-аккаунты теперь используют только официальные Minecraft Services для смены скина и плаща.
- Восстановлено отображение offline-скинов для пользователей с Microsoft-аккаунтом, запустивших игру через Purpur Launcher.
- Добавлено обновление сессии Microsoft перед запуском игры.
- Полностью удалены старый локальный сервер скинов и сторонний агент авторизации.
- Библиотека Purpur теперь загружает offline-скины напрямую с `bedrockmonitoring.ru` по HTTPS и не подменяет лицензированные профили.
